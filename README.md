# List Manager
## Installation
Firstly clone the project
```bash
git clone https://github.com/ClientSiderz/List-Manager
```
### Automatic
#### Windows
Then just execute `run_windows.bat`
#### Other
Then open terminal and run
```bash
./run_other.sh
```
### Manual
Open terminal and run
```bash
python listmanager.py
```
like every other python file
